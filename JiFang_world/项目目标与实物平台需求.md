# 机房巡检项目：目标与实物平台需求

更新日期：2026-10-21。本文用于跨 Agent 交接，仅记录项目目标、实物平台及尺寸约束。尺寸来自项目方输入，未经厂商规格或实物测量复核。

## 1. 项目目标

搭建以机器狗为移动底盘、伸缩杆为升降机构、云台相机为视觉传感器的机房巡检平台，识别机柜各机箱上的二维码，并将识别结果关联至对应设备/高度。

当前阶段重点：在保留已采购设备的前提下，确定相机、镜头、安装方式和拍摄姿态，使**最底部二维码能够可靠解码**。上部二维码可通过抬升相机观察，不要求单帧覆盖整柜。

## 2. 实物平台

安装关系：**机器狗 → 伸缩杆 → 摄像头云台 → 摄像头**。

| 部件 | 项目输入/约束 |
| --- | --- |
| 移动底盘 | 候选为宇树 A2W 或云深处山野 M20，型号尚未最终确定。 |
| 机器狗站立高度 | 约 60 cm；伸缩杆实际安装面距地高度需实测。 |
| 伸缩杆 | 高度范围 60–120 cm；按总高理解，对应可伸缩量约 60 cm，最终以实物为准。 |
| 摄像头云台 | 高度约 10 cm；支持调整拍摄朝向，所需 yaw/pitch 范围待确定。 |
| 摄像头 | 具体型号、有效传感器尺寸、焦距、视场角及分辨率未提供，需核对现有设备与采购状态。 |
| 已购约束 | 相关设备已采购，无法退换；优先保留主体设备，评估安装与使用方式的改善。 |

若将机器狗站立高度视为伸缩杆安装面高度，并将云台高度全部计入竖向叠加：

```text
最低安装高度 ≈ 0.60 + 0.60 + 0.10 = 1.30 m
最高安装高度 ≈ 0.60 + 1.20 + 0.10 = 1.90 m
```

**1.30–1.90 m 是尺寸叠加估算，不能直接视为已确认的相机光心高度。** 实际高度还取决于安装面、连接件、相机在云台上的光心偏移及云台姿态。此前提到的 1.30–1.80 m 范围与本次尺寸叠加不同，需用实物确认最终上限；最低高度约 1.30 m 是当前主要约束。

## 3. 巡检对象与空间尺寸

| 项目 | 尺寸/要求 |
| --- | --- |
| 机柜总高 | 参考照片标注约 217.7 cm。 |
| 机箱与层间结构 | 底部约 10 cm；底层 3U，其上八组 4U，组间隔板约 4 cm；顶部约 20 cm。1U≈4.445 cm。 |
| 二维码 | 每个 1U 机箱一张，约 4×4 cm，位于机箱正面左侧；按当前布局共 35 张。 |
| 二维码内容 | 对应机箱的中心距地高度值；实物贴标时应明确单位与高度基准。 |
| 最低位重点目标 | 底部三个机箱中心高度约为 12.2、16.7、21.1 cm，来自参考尺寸推算，实物需复核。 |
| 拍摄距离 | 当前基准为相机光心至机柜正面平面的水平距离约 60 cm；允许后退范围取决于实际通道，尚未确认。 |
| 未确定尺寸 | 机柜宽深、通道净宽、底盘外形与转向空间、安装偏移。不得将这些尺寸当成已知实测值。 |

## 4. 功能与验收要求

- 机器狗能够移动至机柜前的可用拍摄位置；伸缩杆负责升降，云台负责调整朝向。
- 镜头选型应结合有效传感器尺寸、分辨率、焦距和视场角，不能仅按“广角/长焦”名称判断。
- 重点验收最底部三个二维码：以实际解码成功、内容正确、重复拍摄稳定为准；“进入画面”或“肉眼可见”不等于满足要求。
- 在现场照明、允许停靠距离和实际姿态下验证；是否允许停车采图、所需识别成功率与耗时阈值尚待确定。
- 优先考虑保留现有设备的措施，例如调整拍摄距离、安装偏移或标签朝向；这些措施均需确认现场与机构条件，不属于已批准改造。
- 若二维码用于测高/定位，标签位置、朝向和内容必须保持可追溯的对应关系，不能随意迁移后仍沿用原坐标。

## 5. 后续交接需确认

1. 最终底盘型号、伸缩杆安装面离地高度及姿态变化范围。
2. 伸缩杆 60–120 cm 是否为实际总高范围；云台接口、相机光心位置及实际最低/最高高度。
3. 底盘承载、伸缩杆顶端允许载荷、云台运动范围和安装干涉情况。
4. 摄像头/镜头是否已采购；如已采购，提供具体型号及参数。
5. 通道净宽、最大可用拍摄距离，以及是否允许修改标签朝向或安装支架。
6. 实际二维码尺寸、贴标位置、表面材料，以及扫码成功率和耗时的验收指标。

在以上信息确认前，保留候选方案，不将设备型号、可用行程、改造可行性或扫码可靠性写成已确认结论。
