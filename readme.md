# 机器狗机房巡检仿真

实验按四个阶段整理，结构与启动说明见 [JiFang_world/README.md](JiFang_world/README.md)：

1. [单机柜场景](JiFang_world/01_single_cabinet/README.md)
2. [可升降单相机实验](JiFang_world/02_single_camera/README.md)
3. [机器狗三相机实验](JiFang_world/03_robot_cameras/README.md)
4. [机器狗与双列机柜联合场景](JiFang_world/04_robot_envirments/README.md)

`two_rows_20_racks` 保留原结构，作为第四阶段的机房资产来源。

Ubuntu 依赖与安装步骤见 [安装教程](Ubuntu安装与依赖指南.md)，完整 Python 依赖见 [requirements.txt](requirements.txt)。在项目根目录创建并激活 `.venv` 后，执行 `python -m pip install -r requirements.txt`。
